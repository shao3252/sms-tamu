# SMS TAMU

SMS TAMU ni front-end demo ya app ya Kiswahili ya kushiriki ujumbe na kuwasiliana.

## Mafaili
- `index.html` — muundo wa app na normal-user screens.
- `style.css` — rangi, layout na responsive design.
- `app.js` — feed, profile, posts, search, comments, chat demo na settings.
- `README.md` — maelezo ya project.

## Wasifu wa normal user
- Picha ya wasifu: gusa avatar na chagua picha (hadi 2MB).
- Jina, username na bio: Badili Wasifu kisha Hifadhi.
- Following na Followers: orodha zinafunguka; unaweza ku-unfollow kwenye Following.
- Tabs: Posti Zangu, Zilizopendwa na Zilizohifadhiwa.
- Posti zako: likes, comments, copy, share, save, edit na delete.
- Mipangilio: faragha ya demo, arifa za demo, msaada na kuweka upya demo data.

## Vipengele vingine
- Feed na category filters
- Search ya posts/username
- Kuandika na kushiriki post
- Like, comment, copy, share na save
- Chat UI ya demo

## Data na database
Kwa sasa hii ni front-end demo. Data ya profile, posts, likes, comments, settings na chat huhifadhiwa kwenye localStorage ya browser hii. Haishirikiwi live kati ya watumiaji na chat haitumii server bado.

Following/followers na baadhi ya posts ni sample data ya kuonyesha UI. Admin dashboard haionekani kwa normal users. Admin role itahitaji database/backend authentication na authorization; front-end pekee haiwezi kutoa admin security.

## Kuendesha
Fungua `index.html` kwenye browser au tumia static hosting.
